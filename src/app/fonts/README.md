# Bundled UI fonts

These are the exact Latin WOFF2 assets emitted by the last verified
`next/font/google` production build:

- Inter, variable 100–900
- Montserrat, variable 500–800
- Geist Mono, variable 100–900

They are bundled so production builds and page rendering do not depend on a
live request to Google Fonts. All three font families are distributed under
the SIL Open Font License by their respective authors.
